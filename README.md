# SQL Job Market Analysis 2023

A comprehensive SQL project analyzing over 787,000 job postings from 2023 to uncover salary trends, in-demand skills, top-paying companies, and career opportunities in the data industry.

## Project Overview

This project uses PostgreSQL to explore real-world job market data and answer key business questions relevant to aspiring Data Analysts, Data Scientists, and Data Engineers.

## Tools Used

* PostgreSQL
* VS Code
* SQL

## Key Insights

* Identified the highest-paying Data Analyst positions
* Determined the most valuable skills based on salary
* Analyzed skill demand across the job market
* Ranked companies by average salary offered
* Compared salaries across countries
* Explored monthly hiring trends throughout 2023

## Questions Answered

1. Top 10 highest paying Data Analyst jobs
2. Skills required for top paying jobs
3. Most in-demand skills
4. Top skills by salary
5. Optimal skills (high demand + high pay)
6. Salary categories
7. Monthly job posting trends
8. Jobs above average salary
9. Best companies by salary
10. Country salary rankings
